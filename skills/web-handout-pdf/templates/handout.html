Tech, Performance, Schutz

Schnell. Sicher. Indexierungsgeschützt.

Technische Basis

  • Framework · Version, Router, Sprache
  • Styling · z. B. Tailwind mit token-basiertem Theme
  • Rendering · statisch oder serverseitig
  • Automatische Bild-Optimierung (WebP/AVIF)
  • Hosting · wo und wie der Auftritt betrieben wird

Vorschau-Schutz

Drei Schichten verhindern, dass die Vorschau öffentlich auftaucht oder ohne Login zugänglich ist:

  • HTTP Basic Auth — User + Passwort vor jeder Seite
  • noindex / nofollow Meta in jedem HTML
  • /robots.txt Disallow: / für alle Crawler
